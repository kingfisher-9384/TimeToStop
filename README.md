### What is it?
TimeToStop is a program designed to regulate screentime on Windows. It works like any other screentime software: users set a timer that starts every time the system is powered on. The timer window is always visible, so users know how much time is left. Once the timer ends, the system shuts down, making users reconsider whether they want to power it on again or go do something else. The timer also cannot be stopped, since closing the window will result in a system shutdown. When the timer is changed it will update only after the next system reboot. In the spirit of usability, users can also choose whether the program launches automatically on system start-up. Changing this setting however, results in a system reboot. This promotes more conscious decision-making.
